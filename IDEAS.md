## Candidate ideas

### Low-poly model packs for the Roblox Creator Store

- Type: product
- Customer: Roblox developers who need ready-made props.
- Problem: making consistent, optimized props takes time.
- One-sentence offer: small themed packs of low-poly, Roblox-ready props.
- Why this could be different: consistent style and clean scale/pivots; not yet proven.
- Free alternative: free Creator Store models, Kenney, Poly Haven.
- Paid alternatives: other paid Creator Store models (not yet surveyed).
- Possible price: $2.99–$9.99 per pack (Roblox allows $2.99–$49.99).
- Startup cost: $0.
- Time to first test: days.
- Main assumption: developers will install, and later pay for, these models over free ones.
- Cheapest validation test: publish 3 free models; check installs/favourites after 14 days.
- Kill criteria: almost no installs after 30 days and 5+ published models.
- Status: optional side test (not the main plan since 2026-10-16)

### Beginner Roblox Studio education

- Status: paused — needs credibility first; could later become faceless content documenting the model-pack work.

- Test: publish a focused tutorial or offer a small paid workshop and measure signups or purchases.

### Steal a Meme launch

- Type: game
- Status: paused, kept private (user decision, 2026-10-16: market judged over-exploited). Details in `docs/games/steal-a-meme-summary.txt`
- Main assumption: a themed Steal a Brainrot-style game can retain players for 28 days; the creators of the original have filed at least four lawsuits against clones (user's own research), so avoid copyrighted characters.
- Cheapest validation test: publish with minimal visuals, spend 50–100 $ on ads at most for a first test, read retention.
- Kill criteria: poor retention after the ad test, so no more than 150–300 $ total.

### Rogue Tamer

- Type: game
- Status: build (main project since 2026-10-16). Next: smallest release real players can try, then measure retention
- Main risks: huge scope, turn-based combat is less sticky on Roblox, resemblance to Pokémon.

### Reusable incremental game factory (Roblox)

- Type: game / tool
- Customer: Roblox players (each game); the kit itself is for the user's own reuse.
- Problem: each new game rebuilds data saving, economy, upgrades, prestige, purchases, and UI from scratch.
- One-sentence offer: a data-driven kit (Rojo + git) where a new incremental game is a theme, assets, and one unique mechanic.
- Why this could be different: unknown; depends on the unique mechanic of each game.
- Free alternative: free Creator Store tycoon/simulator kits.
- Startup cost: $0 (tools are free); optional 50–100 $ ad test per game.
- Time to first test: game 1 in ≤ 3 weeks of work.
- Main assumption: a small incremental game with a clear twist retains players well enough to be shown by the algorithm.
- Cheapest validation test: build game 1 with clean modules, closed test plus a small ad test; extract the kit only when starting game 2.
- Kill criteria: D1/D7 retention thresholds to be set before the test (unknown which numbers are good today; research first).
- Status: waiting — after Rogue Tamer's closed test (decision 2026-10-16). Plan in `docs/AUDIT_2026-10-16.md` section 6.
